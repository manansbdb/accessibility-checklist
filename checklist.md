# A11y Checklist / Checklist A11y

Status: Pass | Fail | N/A

## English

### Perceivable
- [ ] Images have meaningful `alt` (or empty when decorative)
- [ ] Text contrast meets WCAG AA (4.5:1 normal / 3:1 large)
- [ ] Content is not conveyed by color alone
- [ ] Captions/transcripts for time-based media where required

### Operable
- [ ] All interactive elements reachable by keyboard
- [ ] Visible focus indicator on focused controls
- [ ] No keyboard traps
- [ ] Skip link or equivalent landmark navigation
- [ ] Touch targets are large enough (approx. 44×44 CSS px)

### Understandable
- [ ] Page `lang` attribute is set
- [ ] Form labels associated with inputs
- [ ] Errors are identified and described in text
- [ ] Consistent navigation and identification

### Robust
- [ ] Valid, semantic HTML landmarks/headings
- [ ] Custom widgets expose correct roles/states/names (ARIA)
- [ ] Works with zoom to 200% without loss of content

## Português

### Perceivable (Perceptível)
- [ ] Imagens com `alt` significativo (ou vazio se decorativas)
- [ ] Contraste de texto cumpre WCAG AA (4.5:1 normal / 3:1 grande)
- [ ] Conteúdo não depende só da cor
- [ ] Legendas/transcrições para media temporal quando exigido

### Operable (Operável)
- [ ] Todos os elementos interativos acessíveis por teclado
- [ ] Indicador de foco visível
- [ ] Sem armadilhas de teclado
- [ ] Skip link ou navegação equivalente por landmarks
- [ ] Alvos de toque suficientemente grandes (~44×44 CSS px)

### Understandable (Compreensível)
- [ ] Atributo `lang` da página definido
- [ ] Labels de formulário associados aos inputs
- [ ] Erros identificados e descritos em texto
- [ ] Navegação e identificação consistentes

### Robust (Robusto)
- [ ] HTML semântico válido (landmarks/headings)
- [ ] Widgets customizados com roles/estados/nomes corretos (ARIA)
- [ ] Funciona com zoom a 200% sem perda de conteúdo

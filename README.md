# Accessibility Checklist / Checklist de Acessibilidade

WCAG-oriented accessibility checklist for web apps and sites.

Checklist de acessibilidade orientada a WCAG para apps e sites web.

## English

Use this checklist during design, development, and QA. Map items to [WCAG 2.2](https://www.w3.org/TR/WCAG22/) success criteria (A / AA / AAA).

### Quick start
1. Copy `checklist.md` into your PR or issue template.
2. Mark each item as Pass / Fail / N/A.
3. Link failures to tickets before merge.

### Scope
- Perceivable, Operable, Understandable, Robust (POUR)
- Keyboard, focus, contrast, semantics, forms, media

## Português

Use este checklist no design, desenvolvimento e QA. Associe itens aos critérios de sucesso do [WCAG 2.2](https://www.w3.org/TR/WCAG22/) (A / AA / AAA).

### Início rápido
1. Copie `checklist.md` para o template de PR ou issue.
2. Marque cada item como Pass / Fail / N/A.
3. Associe falhas a tickets antes do merge.

### Âmbito
- Perceivable, Operable, Understandable, Robust (POUR)
- Teclado, foco, contraste, semântica, formulários, media
